## 构建与回归

使用 GNU MIPS GCC 15.2.0 和 requirements.txt 的固定依赖，另建干净 Git 检出，
从公开远端取得三个固定子模块，不复用对象缓存，重建普通与诊断包并比较 SHA-256。
tag 工作流必须重现上述确切 BDA，同时核对运行记录的哈希和成功状态，才能发布。

主机平台测试检查输入、缩放、原生选择器及取消、GBK 路径、CRC、双槽保存和损坏保护。
实际 MIPS 音量回归执行普通 BDA，覆盖 GBA、GB、GBC 的触摸／左右键调整、0／100 边界、
按 ROM 保存和重载、旧配置读取、非法音量配置保留、未知音量接口回退以及原系统音量恢复。
暂停菜单回归覆盖三核心冻结、完整 CPU/RAM/SRAM 即时存取档、映射、显示和声音开关。
这些检查使用 Unicorn 执行交叉编译代码，固件服务由替身提供，不能用来测量真机性能。

## 完整 H1 固件模拟器

两份确切 BDA 分别部署至同一专用私有测试 NAND，采用完整 V1.41 固件与 QEMU `bbkh1`，
不改动原设备 dump，不注入固件服务替身。验证均从原生系统文件选择器进入。

- GBA／GB／GBC 在声音设置中用实体左右键将音量从 100% 调至 70%，暂停期间核心冻结，
  继续后帧计数推进，固件音量读回为 70%。
- GBA 实际 AIC 音频采集：70% 有非零样本；0% 所有样本为零，PCM 时钟和游戏继续运行。
- 更换游戏时原系统音量恢复；重新打开 GBA 从配置恢复 0% 音量。
- 最后在原生选择器取消，回到桌面并正常结束；诊断包测试结束后离线读取日志，
  并核对 NAND 无不完整提交记录。

完整结果见 [普通包](evidence/v0.12.4-native-normal.json) 和
[诊断包](evidence/v0.12.4-native-profile.json)。普通包音量设置截图为本版实际帧缓冲；
README 中其他原有截图保留各自版本和用户来源说明，不能作为新版运行证据。
