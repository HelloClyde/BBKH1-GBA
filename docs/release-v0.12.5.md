## 构建与 MIPS 回归

使用 GNU MIPS GCC 15.2.0 和 requirements.txt 的固定依赖构建普通版及诊断版，
检查 BDA 标题、图标、大小及 SHA-256。tag 工作流在干净检出中构建，并核对上述
确切 BDA 和运行记录，匹配且全部回归成功后才发布。

主机平台测试覆盖选择器/取消、GBK 路径、输入、缩放、CRC 和双槽保存。
实际 MIPS 音量回归覆盖 GBA、GB、GBC 的触摸和左右键 5% 步长、0/100 边界、
配置保存重载、v1 配置读取、损坏配置保留、未知音量接口回退和退出恢复。
暂停菜单回归覆盖三核心冻结、CPU/RAM/SRAM 即时存取档、映射、显示及声音开关。
结果见 [音量回归](evidence/v0.12.5-volume.json) 和 [暂停菜单回归](evidence/v0.12.5-menu.json)。
这些测试用 Unicorn 执行真实 MIPS BDA，固件服务使用替身，不用于测量真机性能。

## 完整 H1 固件模拟器

两份确切 BDA 分别部署至专用私有测试 NAND，使用完整 V1.41 固件和 QEMU `bbkh1`，
从原生文件选择器进入，不改动原设备 dump，不注入服务替身。

- GBA、GB、GBC 的实体键读回序列均为 `100→95→90→85→80→75→70`。
- 三核心的触摸按钮读回均为 `70→65→70`；暂停期间帧计数冻结，继续后推进。
- GBA 的 70% AIC 音频有非零样本；降至 0% 后所有采集样本为零，游戏仍运行。
- 更换游戏后系统音量恢复为原值 51；重新打开 GBA 从配置恢复 0%。
- 最后取消文件选择，回到桌面并正常结束；离线读取日志核对四次游戏退出的图像错误均为 0，
  NAND 无不完整提交记录，诊断版的性能计时 fault 为 0。

完整结果见 [普通版](evidence/v0.12.5-native-normal.json) 和
[诊断版](evidence/v0.12.5-native-profile.json)。README 的 5% 音量截图来自本版普通 BDA
的实际帧缓冲；其他历史截图保留各自版本及用户来源，不能当作新版运行证据。

本次确切构建尚未在真机复测。模拟器结果不代表商业游戏或真机 FPS，其他固件未验证。
固件、NAND、ROM、原始音频和个人存档不随源码或 Release 分发。
