本版将声音设置中的显示条改为可点击和拖动的音量条，按 5% 对齐，范围 0～100%。
触摸开始后持有本次拖动，读取固件校准坐标；即使移动没有产生 GUI 事件也实时更新。
越界拖动限制在音量范围内，松手不会触发其他按钮；仅从音量条触摸区域内开始才调整。
保留加减按钮、实体左右键、按游戏保存、退出恢复系统音量。

依赖未升级：SDK `067fe072`、gpSP `69e86ebe`、gnuboy `c367bb4b`。
工具链为 GNU MIPS GCC 15.2.0，BDA 日期固定 2026-10-16，ZIP 日期固定同日。
tag 工作流从干净检出构建，并核对上述确切 BDA 与运行记录。

## MIPS 回归

普通 BDA 在 Unicorn 中运行真实 MIPS 指令，固件服务使用替身。
`tests/volume_smoke.py` 对 GBA/GB/GBC 检查点击定位、按住拖动、无事件时坐标更新、
重复坐标不重复设置、两端限幅、滑出音量条松手、从外部滑入不调整、按钮取消、
原有 5% 按钮/键盘调节、配置保存/重载、v1 配置兼容与退出恢复。
见 [音量回归](evidence/v0.12.7-volume.json)。

CI 另执行主机测试与既有 MIPS 启动、暂停/即时存档、线性缩放、音频、继续游戏音频、
GB/GBC 和 RTC 回归。CI 执行真实 MIPS 二进制，但不代表完整固件或真机性能。

## 完整 H1 固件模拟器

两份确切 BDA 分别在专用私有 NAND、完整 H1 V1.41 固件和 QEMU `bbkh1` 中运行。
`tools/test_h1_volume_slider_native.py` 从原生文件选择器打开开放测试 GBA 卡带，
通过真实 GUI 输入测试，只读调试内存，不替换固件服务：

- 点击音量条两端得到 0% 和 100%。
- 持续按住并移动，固件音量依次为 50、75、100、0、30，期间游戏保持暂停。
- 拖动越过音量条上下边界，松手落在声音开关上，不改变开关。
- 返回并继续游戏，帧数恢复推进，音量保持 30%；换游戏恢复原系统音量。
- 再次打开游戏仍为 30%，通过菜单退出回到系统，QEMU 正常停止。
- 私有 NAND 离线日志正常结束，图像错误和不完整提交记录均为 0；诊断计时 fault 为 0。

见 [普通版](evidence/v0.12.7-native-normal.json) 和
[诊断版](evidence/v0.12.7-native-profile.json)。本版滑条截图来自普通版真实帧缓冲，
其余历史截图保留原版本与来源。

离线日志使用 `tools/read_h1_test_file.py` 提取。诊断日志所在的稀疏 NAND 块
首数据页可未使用，提取器核对记录的最后有效页提交标记、序号和逻辑块编号后读取。
`tests/nand_reader_test.py` 覆盖这种记录，以及未提交、序号不匹配、逻辑块不匹配和
越界末页的拒绝，避免把有效日志漏读或把未完成写入算作成功。

本次确切构建尚未在真机复测，其他固件版本未验证。模拟器不代表商业游戏或真机 FPS。
固件、NAND、测试 ROM、原始日志、音频和个人存档不随源码或 Release 分发。
